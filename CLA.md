# Contributor License Agreement

Thanks for wanting to contribute to ClearGate. Before a pull request can be
merged, you need to agree to this Contributor License Agreement (CLA). It lets
the project accept your work while keeping the licensing flexible enough to
sustain the project long term.

## How to accept

Sign your commits off with the Developer Certificate of Origin and, on your
first pull request, leave a comment:

> I have read the CLA document and I hereby sign the CLA.

Sign-off is one flag on `git commit`:

```bash
git commit -s -m "your message"
```

which appends a line like:

```
Signed-off-by: Your Name <your@email.com>
```
